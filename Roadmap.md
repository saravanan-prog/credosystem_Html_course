# 🌐 HTML Roadmap & Syllabus (2026)
### 📌 Introduction

HTML (HyperText Markup Language) is the foundation of web development. It structures web pages and works with CSS and JavaScript.

### 🟢 Phase 1: Basics (Beginner)
🔹 Topics

- What is HTML?
- Structure of HTML document
- Tags, Elements, Attributes
- Headings (`<h1>` to `<h6>`)
- Paragraphs (`<p>`)
- Links (`<a>`)
- Images (`<img>`)

#### 🎯 Practice

- Create a simple webpage
- Add text, links, and images

###  🟡 Phase 2: Text & Formatting
🔹 Topics

#### Text formatting tags:

- `<b>`, `<strong>`
- `<i>`, `<em>`
- `<u>`

#### Lists:

- Ordered (`<ol>`)
- Unordered (`<ul>`)
- Line break (`<br>`)
- Horizontal line (`<hr>`)

#### 🎯 Practice

- Create a blog-style page
- Use lists and formatting

###  🟠 Phase 3: Forms (Important 🔥)
🔹 Topics

`<form>` tag
- Input types:
- text, password, email
- radio, checkbox
- submit button
- Labels (`<label>`)
- Textarea
- Dropdown (`<select>`)

🎯 Practice

Build a login form

Build a registration form

###  🔵 Phase 4: Tables
🔹 Topics

- `<table>`
- `<tr>`, `<td>`, `<th>`
- Table attributes
- Merging cells:
- colspan
- rowspan
- 🎯 Practice
- Create student marks table
- Create timetable

###  🟣 Phase 5: Semantic HTML (VERY IMPORTANT)
🔹 Topics

Semantic tags:

- `<header>`
- `<nav>`
- `<section>`
- `<article>`
- `<footer>`

Importance of semantics

SEO basics

🎯 Practice

Build a structured webpage layout

###  🔴 Phase 6: Multimedia
🔹 Topics

- Audio (`<audio>`)
- Video (`<video>`)
- Iframe (`<iframe>`)

🎯 Practice

Embed YouTube video

Add audio player

### 🟤 Phase 7: Advanced HTML
🔹 Topics

- HTML5 APIs (intro)
- Meta tags
- Favicon
- Responsive design basics
- Accessibility (ARIA basics)

### ⚫ Phase 8: Integration
🔹 Topics

- HTML + CSS
- HTML + JavaScript
- DOM basics

### 🛠️ Projects (Must Do 🔥)
#### Beginner

- Personal profile page
- Simple blog page

#### Intermediate

- Login & signup forms
- Portfolio website
- Advanced
- Landing page
- Multi-page website
