# INTRODUCTION


### Server
- A server is a computer or program that provides services to other computers (clients).
- It receives requests from clients and sends responses back.

### Client

- A client is a **user device** such as a mobile phone, laptop, or desktop computer.
- It sends a **request to the server** and receives the **appropriate response**.
    
### IP Address

- IP Address stands for **Internet Protocol Address**.

- An IP address is a **unique identification number assigned to each device connected to a network**.

- It usually consists of **four numbers separated by dots**.

  Example: `192.168.1.7`

- There are two types of IP addresses:

  - **Public IP Address** – Accessible from the internet.
  - **Private IP Address** – Used within a private network.


### Domain Name System (DNS)

- DNS stands for **Domain Name System**.

- A DNS server helps **map a domain name to an IP address**.

- It translates human-readable website names into IP addresses.

  Example:
  
  `www.google.com` → `142.250.190.78`
