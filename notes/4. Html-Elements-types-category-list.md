HTML Elements Categories List
=============================

    📌 Basic Structure Elements 
    ----------------------------
        These define the overall layout of a webpage.

            🔹 <html>	Root of HTML document
            🔹 <head>	Metadata (title, link, script)
            🔹 <title>	Page title (shown in browser tab)
            🔹 <body>	Visible content
            

    📌 Text Elements  
    -----------------
        Used to structure text content.

            🔹 <h1> to <h6>	    Headings
            🔹 <p>	            Paragraph
            🔹 <br>	            Line break
            🔹 <hr>	            Horizontal line
            🔹 <div>            Division
            🔹 <blockquote>     block + quote
            🔹 <pre>            Preformatted text.

     📌 Inline Text Elements
    ------------------------- 
            <span>    - span
            <a>       - anchor
            <small>   - small text
            <b>       – Bold
            <strong>  – Important text
            <i>       – Italic    
            <em>      – Emphasized text
            <u>       – Underline
            <mark>    – Highlight
            <sup>     – Superscript
            <sub>     – Subscript


    📌 Links & Media  
    ----------------
        Used to embed media.

            🔹 <a>	    Hyperlink
            🔹 <img>	Image
            🔹 <audio>	Audio
            🔹 <video>	Video

    📌 Lists
    ---------
        Used to create lists.

            🔹 <ul>	Unordered list
            🔹 <ol>	Ordered list
            🔹 <dl>	Description list
            🔹 <li> (list item)
            🔹 <dl> (description list)
            🔹 <dt> (term)
            🔹 <dd> (description)
        

    📌 Table Elements
    -------------------

        Used to create tables.

            🔹 <table>	Table
            🔹 <tr>	    Table row
            🔹 <th>	    Table header
            🔹 <td>	    Table data
            🔹 <thead>  Table head
            🔹 <tbody>  Table body
            🔹 <tfoot>  Table foot

    📌 Form Elements (Very Important 🔥)
    --------------------------------------

        Used to collect user input.

            🔹 <form>	    Form container
            🔹 <input>	    Input field
            🔹 <textarea>	Multi-line text
            🔹 <select>	    Dropdown
            🔹 <button>	    Button
            🔹 <label>	    Label for input
    
     📌 Metadata Elements
    ----------------------
        Provide information about the document (not visible on page).
            🔹 <meta>
            🔹 <title>
            🔹 <base>
            🔹 <style>
            🔹 <script>
            🔹 <link>
    
    📌 Semantic Elements (HTML5)
    ----------------------------
        Clearly describe their meaning.

            🔹 <header>
            🔹 <nav>
            🔹 <section>
            🔹 <article>
            🔹 <aside>
            🔹 <footer>
            🔹 <main>
            🔹 <figure>
    
    
  📌 Non-Semmantic Elements 
  --------------------------
        ✅ Example

                <div>  - Divide
                <span> - span
                <b>    - bold
                <i>    - italic
                <u>    - underline
