
## What are Web Technologies

- Web technologies are tools and technologies used to create and manage websites and web applications.

- They help developers build the structure, design, and functionality of websites.

Main web technologies:

### HTML

- HTML (HyperText Markup Language) is used to create the structure of a webpage.

Example:

```<h1>Welcome to Website</h1>
<p>This is my first webpage</p>
```
### CSS

- CSS (Cascading Style Sheets) is used to style and design webpages.

Example:

```
h1 {
  color: blue;
}
```
### JavaScript

- JavaScript is used to add interactivity and dynamic behavior to webpages.

Example:
```
alert("Welcome to my website");
```
