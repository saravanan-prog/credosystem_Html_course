
# Accessibility

Accessibility means making websites usable for everyone, including people with disabilities (vision, hearing, motor, etc.). Modern web development focuses strongly on accessibility so that tools like screen readers can understand the page. ♿

Below are the key things you mentioned.



## 1️⃣ aria-label

- aria-label is used to give a label to an element for screen readers when there is no visible text.

- ARIA stands for Accessible Rich Internet Applications.

- Example
```
<button aria-label="Close menu">X</button>

Here:

Users see X

Screen readers read “Close menu”
```
Another Example
```
<input type="text" aria-label="Search">
```
## 2️⃣ alt Attribute


- The alt attribute describes images for people who cannot see them.

- Example
```
<img src="dog.jpg" alt="Golden retriever playing with a ball">

If the image cannot load or a screen reader is used, the alt text is read.
```

Decorative Image
```
<img src="design.png" alt="">

Empty alt tells screen readers to ignore the image.
```
