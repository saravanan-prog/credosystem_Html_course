# `<script>`

The `<script>` tag in HTML is used to add JavaScript to a webpage. JavaScript makes the webpage interactive and dynamic (buttons, forms, animations, etc.). ⚡

## 1️⃣ Basic Syntax
```<script>
JavaScript code
</script>
```
Example
```<script>
alert("Hello World");
</script>
```


2️⃣ Script Inside HTML (Internal JavaScript)

```
<!DOCTYPE html>
<html>
<body>

<h1>My Website</h1>

<script>
console.log("Welcome to my website");
</script>

</body>
</html>
```


# 3️⃣ External JavaScript File (Best Practice) ⭐

JavaScript is usually written in a separate .js file.

Step 1: Create file

script.js
```
console.log("Hello from JavaScript");
```
Step 2: Link it in HTML
```
<script src="script.js"></script>
```

Example:
```
<!DOCTYPE html>
<html>
<body>

<h1>My Website</h1>

<script src="script.js"></script>

</body>
</html>
```
