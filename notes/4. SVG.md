## SVG 

- SVG stands for Scalable Vector Graphics. It is used in HTML to display vector images that can scale to any size without losing quality. 📐🖼️

- Unlike normal images (.jpg, .png), SVG images are defined using XML code.

1️⃣ Basic SVG Example
```
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="blue" />
</svg>
```
#### Output
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="blue" />
</svg>


 Explanation

| Attribute | Meaning         |
| --------- | --------------- |
| `width`   | SVG width       |
| `height`  | SVG height      |
| `cx`      | circle center X |
| `cy`      | circle center Y |
| `r`       | radius          |
| `fill`    | color           |



This creates a blue circle.

2️⃣ SVG Rectangle Example
```
<svg width="200" height="100">
  <rect width="200" height="100" fill="green" />
</svg>
```

3️⃣ SVG Line Example
```
<svg width="200" height="100">
  <line x1="0" y1="0" x2="200" y2="100" stroke="black" stroke-width="2"/>
</svg>
```

6️⃣ SVG vs PNG vs JPG
| Feature   | SVG          | PNG       | JPG    |
| --------- | ------------ | --------- | ------ |
| Scalable  | ✅            | ❌         | ❌      |
| File size | Small        | Medium    | Small  |
| Best for  | Icons, logos | UI images | Photos |

7️⃣ Common SVG Shapes
Tag	Shape
| Tag         | Shape          |
| ----------- | -------------- |
| `<circle>`  | Circle         |
| `<rect>`    | Rectangle      |
| `<line>`    | Line           |
| `<ellipse>` | Ellipse        |
| `<polygon>` | Polygon        |
| `<path>`    | Complex shapes |
