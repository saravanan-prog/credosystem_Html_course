Semantic HTML
=============
   👉  Semantic HTML uses meaningful tags that clearly describe the purpose of the content.
   👉  Improves readability of code
   👉  Better SEO
   👉  Helps screen readers (accessibility)
   👉  Easier website structure understanding

      Example: Instead of using: <div>
         <header> → Header section
         <footer> → Footer section
         

      🏗️ Page Structure Tags

         🔹 <header>	   Top section of a page or section
         🔹 <nav>	      Navigation links
         🔹 <main>	   Main content of the page (only one per page)
         🔹 <section>	Thematic grouping of content
         🔹 <article>	Independent, self-contained content
         🔹 <aside>	   Sidebar or related content
         🔹 <footer>	   Bottom section of a page or section
      
      📝 Text Content Semantic Tags

        🔹 <h1> – <h6>	   Headings
        🔹 <p>	            Paragraph
        🔹 <strong>    	   Important text
        🔹 <em>	         Emphasized text
        🔹 <mark>	         Highlighted text
        🔹 <small>	      Small print
        🔹 <blockquote>	   Block quotation
        🔹 <cite>	         Citation
        🔹 <q>	            Inline quotation
        🔹 <abbr>	         Abbreviation
        🔹 <address>	      Contact information
        🔹 <time>	         Date/time value
        🔹 <code>	         Code snippet
        🔹 <pre>	         Preformatted text
      
      📦 Media & Content Tags
      
         🔹 <figure>	      Self-contained content (image, chart, etc.)
         🔹 <figcaption>	Caption for figure
         🔹 <audio>	      Audio content
         🔹 <video>	      Video content

      📋 Forms Semantic Tags
          
         🔹 <form>	   Form container
         🔹 <label>	   Label for input
         🔹 <fieldset>	Group related form elements
         🔹 <legend>	   Caption for fieldset

      📊 Table Semantic Tags
          
         🔹 <table>	Table container
         🔹 <thead>	Table header
         🔹 <tbody>	Table body
         🔹 <tfoot>	Table footer
         🔹 <th>	Table header cell

🧠 Why Semantic HTML is Important
===================================
  
   🔹 <header> Represents introductory content.

         Usually contains:

            Website title
            Logo
            Heading
            Navigation (sometimes)

   🔹 <nav> Contains navigation links.

         <nav>
            <a href="#">Home</a>
            <a href="#">About</a>
            <a href="#">Contact</a>
         </nav>

   🔹 <section> : Represents a section of content.

         <section>
            <h2>About Us</h2>
            <p>We are learning HTML.</p>
         </section>

   🔹 <article> : Represents independent content.

         Examples:
            Blog post
            News article
            Forum post

            <article>
               <h2>HTML Basics</h2>
               <p>This is an article about HTML.</p>
            </article>


   🔹 <footer> : Represents footer section.

         Usually contains:
         Copyright
         Contact info
         Author name

         <footer>
            <p>© 2026 My Website</p>
         </footer>



Complete Example Page
=====================

<!DOCTYPE html>
   <html>
      <head>
         <title>Semantic HTML Example</title>
      </head>
   <body>

      <header>
         <h1>My School Website</h1>
      </header>

      <nav>
         <a href="#">Home</a>
         <a href="#">About</a>
         <a href="#">Contact</a>
      </nav>

      <section>
         <h2>Welcome</h2>
         <p>This is our school website.</p>
      </section>

      <article>
         <h2>Latest News</h2>
         <p>Annual day will be held next month.</p>
      </article>

      <footer>
         <p>© 2026 ABC School</p>
      </footer>

   </body>
</html>
