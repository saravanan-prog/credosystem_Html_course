## HTML Entities

HTML entities are special codes used to display reserved characters or special symbols in HTML.


| Character | HTML Entity | Meaning            |
| --------- | ----------- | ------------------ |
| `<`       | `&lt;`      | Less than          |
| `>`       | `&gt;`      | Greater than       |
| `&`       | `&amp;`     | Ampersand          |
| `"`       | `&quot;`    | Double quote       |
| `'`       | `&apos;`    | Single quote       |
| Space     | `&nbsp;`    | Non-breaking space |
| ©         | `&copy;`    | Copyright          |
| ®         | `&reg;`     | Registered         |
| ₹         | `&#8377;`   | Indian Rupee       |
| ♥         | `&hearts;`  | Heart              |
