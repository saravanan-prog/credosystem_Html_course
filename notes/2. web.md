
# What is the World Wide Web (WWW)

- The World Wide Web (WWW) is a system of web pages and websites that are accessed through the internet.

- It uses web browsers to view content.

- Web pages are connected through hyperlinks.



## 1️⃣ Webpage

- A webpage is a single document or page on the internet.

- It is created using HTML.

- A webpage contains text, images, videos, and links.

- Each webpage has a unique URL.

## 2️⃣ Website
- A website is a collection of multiple webpages connected together under one domain name.

Example structure:
```
Website
│
├── Home Page
├── About Page
├── Contact Page
└── Services Page
```
Example websites:

- Google
- Amazon
- Wikipedia


## 3️⃣ Web Application
- A web application is a dynamic website that allows users to interact with the system and perform tasks.

#### Features:

- User login

- Database interaction

- Real-time updates

- User input processing

Examples:
```
Gmail
Google Docs
Facebook
```
