## 1️⃣ `<link>` Tag

The <link> tag with rel="stylesheet" is used to connect an external CSS file to an HTML page. This is the best and most common way to apply styles to a website. 🎨

###  Basic Syntax

```
<link rel="stylesheet" href="style.css">
```

| Attribute          | Meaning                                               |
| ------------------ | ----------------------------------------------------- |
| `rel="stylesheet"` | tells the browser the linked file is a CSS stylesheet |
| `href="style.css"` | path to the CSS file                                  |

Example

```
<!DOCTYPE html>
<html>
<head>

<title>My Website</title>

<link rel="stylesheet" href="style.css">

</head>

<body>

<h1>Hello World</h1>

</body>
</html>
```
# 2️⃣ ` <link rel="icon">`

The `<link rel="icon">` tag is used to add a favicon (small icon) to a website. The favicon appears in the browser tab, bookmarks, and sometimes in search results. 🌐🧩

Basic Syntax
```
<link rel="icon" href="favicon.ico" type="image/x-icon">
<link rel="icon" type="image/png" sizes="32x32" href="favicon-32.png">
<link rel="icon" type="image/png" sizes="16x16" href="favicon-16.png">
```

| Attribute    | Meaning                                      |
| ------------ | -------------------------------------------- |
| `rel="icon"` | Tells the browser this file is the site icon |
| `href`       | Path to the icon file                        |
| `type`       | Image type (optional but recommended)        |

Example
```
<!DOCTYPE html>
<html>
<head>

<title>My Website</title>
<link rel="icon" href="favicon.ico" type="image/x-icon">

</head>
<body>

<h1>Welcome</h1>

</body>
</html>
```
