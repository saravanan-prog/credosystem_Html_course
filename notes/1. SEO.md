## 1️⃣ `<title>` Tag

- The `<title>` tag defines the title of the webpage.

## 2️⃣ `<meta>` Tag

- The `<meta>` tag provides metadata (information about the webpage).
- It is placed inside the `<head>` section.
- Example


### `<meta charset="UTF-8">`

- Defines character encoding
- Helps browsers display text correctly.


| Encoding                 | Can store                                              | Example                                      |
| ------------------------ | ------------------------------------------------------ | -------------------------------------------- |
| **ASCII**                | Basic English only                                     | `Hello 123 !@#` ✅<br>`தமிழ்` ❌<br>`😊` ❌     |
| **UTF-8**                | Almost every language + emoji                          | `Hello` ✅<br>`தமிழ்` ✅<br>`你好` ✅<br>`😊` ✅   |
| **UTF-16**               | Same characters as UTF-8, different storage            | `Hello` ✅<br>`தமிழ்` ✅<br>`😊` ✅             |
| **UTF-32**               | Same characters as UTF-8, every character uses 4 bytes | `Hello` ✅<br>`தமிழ்` ✅<br>`😊` ✅             |
| **ISO-8859-1 (Latin-1)** | English + many Western European characters             | `Hello` ✅<br>`Café` ✅<br>`தமிழ்` ❌<br>`😊` ❌ |
| **Windows-1252**         | Similar to Latin-1 with extra symbols                  | `Hello` ✅<br>`€` ✅<br>`Café` ✅<br>`தமிழ்` ❌  |



## 3️⃣ `<meta name="description">`

- This gives a short description of the webpage.
- Search engines like Google often show this in search results.

```
<meta name="description" content="Learn HTML basics with simple examples and tutorials.">
```

## 4️⃣ `<meta name="viewport">`

- This tag makes the website responsive on mobile devices. 📱

- Without it, websites look zoomed out on phones.

- Example

```
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

| Attribute            | Meaning                          |
| -------------------- | -------------------------------- |
| `width=device-width` | Page width matches device screen |
| `initial-scale=1.0`  | Normal zoom level                |

## 🧠 Complete Example

```
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
    <meta charset="UTF-8">
    <meta name="description" content="Simple HTML learning website">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
<body>
  <h1>Hello World</h1>
</body>
</html>
