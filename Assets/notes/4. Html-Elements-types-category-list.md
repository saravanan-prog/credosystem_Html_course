# HTML Elements Categories List

## 1. Basic Structure Elements    
-  These define the overall layout of a webpage.
```
        <html>   - Root of HTML document  
        <head>   - Metadata (title, link, script)     
        <title>  - Page title (shown in browser tab)     
        <body>   - Visible content
```           

##  2.  Text Elements      
 Used to structure text content.


```
        <h1> to <h6>    -   Headings 
        <p>            -   Paragraph    
        <br>            -   Line break      
        <hr>            -   Horizontal line
        <div>           -   Division
        <blockquote>    -   block + quote
        <pre>           -   Preformatted text
```
## 3. Inline Text Elements
```             
            <span>    -     span
            <a>       -     anchor
            <small>   -     small text
            <b>       –     Bold
            <strong>  –     Important text
            <i>       –     Italic    
            <em>      –     Emphasized text
            <u>       –     Underline
            <mark>    –     Highlight
            <sup>     –     Superscript
            <sub>     –     Subscript

```
## 4. Links & Media  
    
- Used to embed media.
```
    <a>	        -    Hyperlink
    <img>       -    Image
    <audio>     -    Audio
    <video>     -	 Video
```
##  5.  Lists
    
-  Used to create lists.
```
    <ul>	    -   Unordered list
    <ol>	    -   Ordered list
    <dl>	    -   Description list
    <li>        -   (list item)
    <dl>       -   (description list)
    <dt>       -   (term)
    <dd>       -   (description)
```        

## 6. Table Elements
    
- Used to create tables.
```
            <table>	    - Table
            <tr>	    - Table row
            <th>	    - Table header
            <td>	    - Table data
            <thead>     - Table head
            <tbody>     - Table body
            <tfoot>     - Table foot
```
## 7. Form Elements (Very Important 🔥)
    

        Used to collect user input.

            🔹 <form>	    -   Form container
            🔹 <input>	    -   Input field
            🔹 <textarea>	-   Multi-line text
            🔹 <select>	    -   Dropdown
            🔹 <button>	    -   Button
            🔹 <label>	    -   Label for input
    
##  8. Metadata Elements
    
- Provide information about the document (not visible on page).

```
    <meta>       - Provides metadata about the webpage (charset, description, viewport, etc.).
    <title>      - Sets the title displayed in the browser tab.
    <style>      - Contains internal CSS styles for the webpage.
    <script>     - Contains or links JavaScript code.
    <link>       - Connects external resources such as CSS files or icons.
```    
##  9. Semantic Elements (HTML5)
    
- Clearly describe their meaning.
```
    <header>         -   Defines the header section of a page or section.
    <nav>            -   Contains navigation links or menus. 
    <section>        -   Groups related content into a section.
    <article>        -   Represents independent, self-contained content.
    <aside>          -   Contains sidebar or supplementary content.
    <footer>         -   Defines the footer section of a page or section.
    <main>           -   Contains the main content of the document.
    <figure>         -   Groups media content like images with captions. 
```
